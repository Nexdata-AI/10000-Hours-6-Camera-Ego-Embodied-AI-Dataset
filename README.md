# 10000-Hours-6-Camera-Ego-Embodied-AI-Dataset

## Description
A multimodal embodied AI dataset totaling 10,000 valid hours, collected with a six-camera Ego head-mounted device, and subjected to multiple rounds of quality inspection, AI preprocessing, and fine-grained manual action segmentation and annotation. It covers 25 categories of real-world business scenarios and outputs multi-sensor data in MCAP format along with task-action labels in multiple languages including Chinese, English, Japanese, and Korean.

For more details, please refer to the link: https://www.nexdata.ai/datasets/embodied-ai/2264?source=Github
